# The Legend of Tun Teja

A 3D action adventure game built with Unity, based on the Malaysian folklore of Tun Teja.

## How to Play

Download from the [`Build/`](https://github.com/Shrlnrm/LegendOfTunTeja/tree/main/Build) folder.

1. Download `The_Legend_of_Tun_Teja.zip`
2. Extract it
3. Run `The Legend of Tun Teja.exe`

Requires Windows 10/11 (64-bit) and a DirectX 11 compatible GPU.

## Built With

- Unity
- C#
- Windows Standalone (DirectX 12)
